# 智能任务管理系统

一个简洁美观的任务管理系统，支持任务添加、优先级设置、状态切换、筛选和删除。

## 技术栈

- **前端**: React 19 + TypeScript + Tailwind CSS + shadcn/ui
- **后端**: NestJS 10 + Supabase
- **数据库**: Supabase PostgreSQL

## 功能

- 输入框 + 优先级下拉（高/中/低），点击添加任务
- 任务列表：标题、优先级标签、完成状态
- 每条任务：完成/未完成切换 + 删除按钮
- 按优先级筛选：全部 / 高 / 中 / 低
- 任务按创建时间倒序，已完成任务标题加删除线

## 环境变量

在 Supabase 项目中获取以下配置，并设置为环境变量：

| 变量名 | 说明 |
|--------|------|
| `SUPABASE_URL` | Supabase 项目 URL |
| `SUPABASE_ANON_KEY` | Supabase anon / publishable key |

## 数据库建表

在 Supabase Dashboard 的 SQL Editor 中执行以下建表语句：

```sql
create table tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);
```

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```
